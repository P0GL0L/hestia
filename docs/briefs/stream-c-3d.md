# Stream C — 3D viewport

Owner: Cursor. Do not start before `contracts-v1.0`.

## Start point

`contracts-v1.0` mesh types and the mock geometry engine. Switch to real meshes at `geometry-v0.5`.

## Done when

- [ ] RealityKit view renders element meshes with materials and textures.
- [ ] Orbit, pan, zoom. Walk mode with wall collision and stair climbing.
- [ ] Storey peel and per-layer visibility. Walls fade when the camera is close.
- [ ] Sun position from date, time, latitude, longitude, and north angle, with shadows.
- [ ] Section box driven by Stream A's slicing API.
- [ ] Click-to-select synced with 2D.
- [ ] PNG screenshot export at a chosen resolution, and walkthrough video export along a drawn path.
- [ ] Holds 60 fps on a 200-wall furnished house on an M-series Mac, measured and linked on the issue.

## Out of scope

Wall join math and sheet layout.
