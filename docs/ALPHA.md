# Hestia alpha

This is the bar for a complete alpha. It is not Plan7Architect Pro parity and not a permit set.

## Done when

A fresh Mac user can:

1. Draw a 6-room, one-storey cottage with straight walls, doors, and windows.
2. Get closed rooms with area.
3. See one hip roof and one straight stair.
4. Orbit the model in 3D.
5. Export a schematic PDF floor plan and a DXF of the walls.
6. See a visible stamp: schematic / not for construction.

## Not in the alpha

Exotic roofs, spiral stairs, framing, 300 catalog items, four model providers, MCP, walk-mode video, notarized DMG, and a sealed drawing set.
